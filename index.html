About

I am a computer science graduate and independent researcher working across deep learning for biomedical imaging, quantum machine learning, and trustworthy model evaluation.

My current work spans colorectal histopathology grading, bone-marrow cytology, tuberculosis microscopy, and two-photon calcium imaging; quantum–classical methods for feature selection and classification using QAOA, variational circuits, and training-free quantum kernels on both simulators and IBM Quantum hardware; and evaluation under calibration, data-leakage, and subgroup-fairness constraints.

I care about results that hold up. Every project below reports what the experiments actually showed — including where quantum methods only reach parity with classical baselines, and where a strong baseline beats the method I built. Code is public for all of them.

Research Themes

Trustworthy evaluation of medical models

Most of my work starts by auditing the evaluation itself — patient- and specimen-disjoint splitting, image-hash de-duplication, calibration, and subgroup analysis — because leakage and miscalibration silently inflate the numbers that clinical claims rest on. In one study, ignoring specimen grouping alone inflated macro F1 by up to 9.6 points.

Quantum–classical machine learning

I formulate learning problems for near-term quantum hardware — feature selection as a QUBO solved with QAOA, variational circuit classifiers, and training-free quantum kernels with closed-form variance guarantees — and test them against parameter-matched classical baselines on real hardware, reporting parity as parity.

Learning under distribution and privacy constraints

Federated training with realistic non-IID clients, knowledge distillation for edge deployment, and selective prediction that decides which outputs to trust — including where these methods fail, such as federated accuracy collapsing under severe client heterogeneity.

DARE-FS — Detecting and Repairing Class-Specific Feature-Selection Harm under review, ICTAI 2026

Feature selection can leave the headline metric almost unchanged while making a rare class substantially harder to detect — the majority classes absorb the loss and hide it. DARE-FS is a selector-agnostic, post-selection operator that detects class-wise damage introduced by any selector, attributes it to specific discarded features through validation-based add-back, and repairs the subset by restoring the smallest set of features needed to recover the harmed classes.

Evaluated on untouched outer-test folds under nested cross-validation across four real datasets spanning network intrusion detection and clinical tabular data, plus synthetic data with planted ground-truth minority features and documented negative controls. First-author work; code and full results released on acceptance.

PCMMD — Federated Learning and Knowledge Distillation for Plasma Cell Detection code →

Binary plasma vs. non-plasma classification of bone-marrow cell crops in multiple myeloma, benchmarked across four learning regimes: centralized 5-fold cross-validation, few-shot data-efficiency curves, knowledge distillation for edge deployment, and federated training with one client per patient.

Findings. Federated training matches centralized accuracy under IID and mild non-IID partitions (best-round test accuracy 0.990), but collapses under severe heterogeneity (Dirichlet α = 0.1: 0.883). Splits are patient-disjoint with image-hash de-duplication; the federated setup is a decentralized training simulation and does not implement differential privacy.

Direct-WAM — Self-Supervised Denoising for Two-Photon Calcium Imaging code →

A theory-and-measurement study of self-supervised denoising objectives, treating each objective through its systematic bias vector. This yields a per-objective error floor, a condition under which an ensemble beats its best member, a bound on what distillation transfers, and an imaging-speed law.

QCIDS — Quantum–Classical Feature Selection for Intrusion Detection code →

Feature selection for network intrusion detection cast as a QUBO and solved several ways on equal footing: QAOA at p = 1, 2, 3 on simulators and on IBM hardware, simulated quantum annealing, and classical selectors. Every solver feeds the same downstream classifier under the same leakage-free cross-validation, so any difference traces to the selected feature subset alone.

At k = 15 the greedy selector falls into a trap: it keeps three globally informative features that carry almost no per-class information for Ransomware, whose F1 drops to 0.48. Combinatorial QUBO search escapes this and recovers Ransomware F1 to 0.82 (paired test p = 0.045). Notably, some classical selectors escape the trap too — the honest claim is robustness of combinatorial search over greedy ranking, not quantum superiority. On NF-UNSW-NB15 and X-IIoTID no solver separates.

Q-PlasmaNet — Hybrid Classical–Quantum Classifier code →

A frozen CNN backbone extracts features on GPU; a 4–8 qubit variational quantum circuit (PennyLane) sits on top as the classifier head and trains on CPU. The question was whether a NISQ quantum head can match strong classical baselines at the same parameter budget — not whether it beats them.

CovNCG — Training-Free Dense Quantum Feature Maps code →

A training-free quantum kernel built from non-commuting multi-feature generator blocks, packing three features into two qubits. The kernel variance has a closed form, so the bandwidth can be tuned to avoid exponential concentration instead of guessed at — no training, no architecture search.
