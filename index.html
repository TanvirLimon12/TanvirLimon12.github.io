About

I studied computer science at Independent University, Bangladesh, and now work as an independent researcher. Most of what I do is machine learning for security problems.

Four of my papers were accepted in 2026. The first-author one shows that cutting a feature set can leave overall accuracy almost untouched while making a rare attack class far harder to detect, and gives a way to find the harmed classes and repair the subset. Another pairs a vision-language model with an LLM, both running on the user's own machine, so web pages are screened without anything leaving the device.

A lot of my time goes into how models get evaluated. Leakage between splits and poor calibration make results look better than they are, so I check for both before anything else. When a method does not beat its baseline, I say so. All the code is public.

Research Themes

Machine learning for network defence

Intrusion detection on industrial IoT traffic, and a threat detection agent that runs locally in the browser. The part I find most interesting is what happens to rare attack classes: cutting the feature set barely moves overall accuracy while quietly making ransomware much harder to catch.

Quantum and combinatorial optimization

I take a learning problem, write it in a form near-term quantum hardware can run, and test it against classical methods with the same parameter budget. So far the honest result is parity, not an advantage.

Medical imaging, and making sure the numbers are real

Histopathology, cytology and microscopy, with most of the effort going into evaluation. In the colorectal work, splitting by image instead of by specimen made macro F1 look up to 9.6 points better than it was.
