I am a computer science graduate and independent researcher. My work covers network security, medical image analysis and quantum machine learning, and in all three I focus on whether the results hold up.

Four of my papers were accepted in 2026. One of them shows that cutting a feature set can leave overall accuracy almost untouched while making a rare attack class far harder to detect, and gives a way to find the harmed classes and repair the subset.

I hold a BSc in Computer Science from Independent University, Bangladesh, and work independently in Boca Raton, Florida. Across everything I do, the recurring question is whether a reported number would survive someone checking it.

03 / Code and experimentsResearch projects

Work with public code behind it. All projects with figures and tables →

  • PhishGuard A browser agent that screens a page by looking at it rather than checking it against a blocklist. A vision-language model reads the rendered screenshot while a second model reasons over the URL string, both 4-bit quantized and running on the user's own machine, so no URL or screenshot leaves the device.
  • QCIDS Feature selection for network intrusion detection written as a QUBO, then solved four different ways on equal footing: QAOA at three depths, simulated annealing, and the classical selectors people actually use. Every solver hands its subset to the same classifier under the same leakage-free cross-validation, so any difference traces to the features chosen.
  • DARE-FS Cutting a feature set can leave overall accuracy flat while a rare class quietly loses most of its detectability. This runs after any selector: it detects which classes were harmed, traces the loss to specific discarded features by adding them back, and restores the smallest set that brings those classes back. Accepted at ICTAI 2026.
  • CovNCG A quantum kernel that needs no training at all. Each block packs three features into two qubits using generators that do not commute, and the variance of the resulting kernel has a closed form, so the bandwidth can be computed instead of guessed and kernel concentration can be predicted before it ruins the classifier.
  • Q-PlasmaNet A frozen CNN backbone with a four to eight qubit variational circuit on top as the classifier head. The question is deliberately narrow: at an equal parameter budget, can a quantum head match a classical one? It ties with a parameter-matched MLP and sits below a full CNN thousands of times larger. Parity, not advantage.
  • PCMMD Plasma cell detection in bone marrow crops for multiple myeloma, run four ways to see what each setting costs: centralized training, few-shot curves, distillation into a student small enough to deploy, and federated training with one client per patient. Folds are patient-disjoint with image-hash de-duplication.
  • Direct-WAM Denoising two-photon calcium recordings, where no clean ground truth exists. Each self-supervised objective is analysed through the bias it leaves behind, which yields an error floor per objective, a condition for when combining several of them helps, and a bound on what a distilled student can inherit.
